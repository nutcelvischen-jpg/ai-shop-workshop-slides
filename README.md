# 輕量級微電商 AI 導購與自動報價系統｜大學生實戰工作坊

零伺服器租用成本、純瀏覽器開發的 180 分鐘大學生實作工作坊教材，整合：

- **前端網站**：GitHub Pages (`index.html`)
- **雲端資料庫**：Google Sheets（`Products` 商品目錄 + `Orders` 訂單紀錄）
- **後端中樞**：Google Apps Script (GAS)
- **AI 導購大腦**：OpenRouter API（`anthropic/claude-haiku-5.5`，強制 JSON 結構化輸出）
- **雙向通知**：`GmailApp`（自動寄送報價信）＋ LINE Messaging API（店家手機成單推播）

## 線上投影片功能

- **簡報操作**：支援鍵盤 `←` / `→`、`Space`、左下角縮圖導覽列，以及瀏覽器列印（`Cmd/Ctrl + P`）匯出一頁一張 PDF 講義。
- **講者備忘錄（按 `N` 鍵）**：內建每頁口語講稿、課堂配速與新手救火話術。
- **一鍵複製程式碼**：第 9 頁（完整 `Code.gs`）、第 10 頁（`testBackend()` 單元測試）與第 12 頁（完整 `index.html`）可直接複製貼上或預覽全碼。
