        CORE CONCEPTS
        
開始動手前，必懂的兩個資安與資料觀念

      

      

        

          CONCEPT A｜資安觀念
          
為什麼 API Key 不能放在前端網頁？

          
    
            
  • ✕放前端 HTML 的風險：任何人按 F12 或檢視原始碼就能抄走你的 OpenRouter 金鑰，額度幾分鐘被盜刷光。
    • 
            
  • ✓放後端 GAS 的保護：GAS 在 Google 雲端執行，顧客永遠看不到程式碼裡的金鑰字串。
    • 
          

        

        

          CONCEPT B｜資料規格
          
為什麼要強制 AI 回傳 JSON 格式？

          
一般聊天會回傳自由長文，程式無法抓取總價；透過 response_format 規定 Haiku 5.5 只交出固定欄位：

          

            
{
  "recommended_items": "濾掛盒 x 2, 隨行杯 x 1",
  "total_price": 1380,
  "reply_message": "給客戶的 80 字貼心建議"
}

            Code.gs（Google Apps Script）
            

              
              
            

          

          
// ====== 1. 填入你的專屬金鑰（請保留雙引號） ======
const OPENROUTER_API_KEY = "貼上你的_OPENROUTER_API_KEY";
const LINE_ACCESS_TOKEN = "貼上你的_LINE_CHANNEL_ACCESS_TOKEN";
const LINE_ADMIN_USER_ID = "貼上你的_LINE_USER_ID_U開頭";

// ====== 2. 接收前端網頁 POST 請求的主程式 ======
function doPost(e) {
  try {
    const params = JSON.parse(e.postData.contents);
    const catalogText = getProductCatalog();
    const aiResult = callOpenRouterAI(catalogText, params.requirement);
    saveOrderToSheet(params.name, params.email, params.requirement, aiResult);
    sendQuoteEmail(params.name, params.email, aiResult);
    sendLineNotification(params.name, params.requirement, aiResult);
    return createJsonResponse({ status: "success", data: aiResult });
  } catch (error) {
    return createJsonResponse({ status: "error", message: error.toString() });
  }
}
